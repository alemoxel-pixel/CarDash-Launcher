## Features

- Five dashboard themes: Theme 1, Theme 2, Theme 3, OBD and OBD Color.
- Clock, weather, calendar, GPS satellites and CPU temperature.
- Media control for any player.
- Weather, CPU temperature, GPS and calendar blocks can be replaced with widgets from installed apps.
- Bottom bar (Back, Home, Recents) and quick-launch buttons.
- Split screen with two apps side by side.
- Vehicle data over OBD-II with an ELM327 Bluetooth adapter: RPM, speed, temperatures, voltage.
- Accent color and backgrounds: solid, gradient, wallpapers, your own image or video.
- English and Russian interface.
- In-app updates.

## Requirements

- Android 8.0 or newer.
- Landscape screen.
- Google Play Services are not required.

Developed and tested on TopWay TS20 (UNISOC, Android 13). On other head units some features may
work differently.

## Installation

1. Download `CarDash-Launcher.apk` from [Releases](../../releases/latest).
2. Allow installation from unknown sources.
3. On Android 13 and newer, open the app info and choose "Allow restricted settings".
4. Set CarDash as the default launcher: CarDash settings → System → Default launcher.

## Permissions

All permissions are optional:

- notification access — music;
- location — weather and GPS;
- Bluetooth — OBD adapter;
- accessibility — Recents button;
- storage — backgrounds and music files.

## Русский

Автомобильный лаунчер-дашборд для Android-магнитол.

### Возможности

- Пять тем дашборда: Тема 1, Тема 2, Тема 3, OBD и OBD Color.
- Часы, погода, календарь, спутники GPS и температура процессора.
- Управление музыкой любого плеера.
- Блоки погоды, температуры процессора, GPS и календаря заменяются виджетами установленных приложений.
- Нижний бар (Назад, Домой, Недавние) и кнопки быстрого запуска.
- Сплит-экран: два приложения рядом.
- Данные автомобиля по OBD-II через Bluetooth-адаптер ELM327: обороты, скорость, температуры,
  напряжение.
- Акцентный цвет и фоны: цвет, градиент, обои, своя картинка или видео.
- Интерфейс на русском и английском.
- Работает при «белых списках» мобильной сети.
- Обновление из лаунчера.

### Требования

- Android 8.0 и новее.
- Горизонтальный экран.
- Google Play Services не нужны.

Разрабатывается и проверяется на TopWay TS20 (UNISOC, Android 13). На других магнитолах часть
функций может работать иначе.

### Установка

1. Скачайте `CarDash-Launcher.apk` в [Releases](../../releases/latest).
2. Разрешите установку из неизвестных источников.
3. На Android 13 и новее откройте свойства приложения и выберите «Разрешить ограниченные настройки».
4. Назначьте CarDash лаунчером по умолчанию: настройки CarDash → Система → Лаунчер по умолчанию.

### Разрешения

Все разрешения необязательны:

- доступ к уведомлениям — музыка;
- геолокация — погода и GPS;
- Bluetooth — OBD-адаптер;
- спецвозможности — кнопка «Недавние»;
- память — фоны и музыка.
